# Mermaid-диаграммы: создание и доводка

## Расположение

- Каждая диаграмма размещается в отдельном markdown-файле в `docs/`, если не сказано иное.

## Подводные камни синтаксиса (mermaid-cli 12)

Общие принципы для mermaid:

1. Для экранирования `<` и `>` используй `&lt;` и `&gt;`, а не `~`
2. Для classDiagram и flowchart лучше использовать `direction LR`

В используемой версии mermaid-cli (mmdc) есть такие особенности:

1. `<br/>` в подписях C4-связей рендерится двумя строками на одной координате y (наложение). В flowchart работает нормально.
2. Две связи между одной парой узлов (C4 `Rel`) дедуплицируются — остаётся последняя, первая исчезает молча.
3. C4-объявления: 5-й аргумент (sprite) отбрасывается молча; 3-й (tech) выводится в стереотипе `[Container: tech]`; 4-й (descr) — строкой в боксе.
4. C4: граница называется `System_Boundary`, не `SystemBoundary`.
5. classDiagram: члены классов рендерятся в `<foreignObject>` — поиском по svg-текстам их не найти, для диагностики можно парсить HTML-контент.
6. Не работают: `UpdateLayoutConfig($direction)` для C4-диаграмм, `%%{init: {"layout": "elk"}}%%` и `{"class": {nodeSpacing, rankSpacing}}` для classDiagram.

## 4. Валидация

- Выполнить рендеринг для проверки синтаксиса и генерации SVG: `python3 scripts/render-diagrams <path>.md --format=svg`
- Применить детектор перекрытий: `python3 scripts/check-overlap <file>.svg`
- Выполнить проверку текста — grep ожидаемых строк по SVG — поскольку рендер может молча потерять текст.

### Рендеринг

После обновления диаграмм вызывай `scripts/render-diagrams <path>.md ...` для рендеринга диаграмм.

- `render-diagrams` принимает список путей к диаграммам (.md или .mmd) и рендерит только их
- Оба скрипта поддерживают опцию `--format=png|svg`, по умолчанию `png`
- Изображение размещается рядом с входным md-файлом
- Внутри используется mmdc: `npx -y -p @mermaid-js/mermaid-cli mmdc ...`

### Детектор перекрытий

Для обнаружения пересечений подпись↔бокс и подпись↔подпись используется скрипт `scripts/check-overlap`, принимающий SVG-рендеринг диаграммы.

- Принимает список путей к входным SVG-файлам
- Печатает список перекрытий (`OVERLAP: ...`) либо статус `OK: no overlaps`

Создать SVG-файл можно скриптом `scripts/render-diagrams`.
